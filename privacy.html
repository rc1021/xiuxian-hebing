我們收集什麼

目前的網頁試玩版不收集任何個人資料：沒有帳號、沒有登入、沒有廣告，也不使用 cookie。下面寫的是匿名統計；排行榜另外會送出道號與成績，見下方「排行榜」；你主動寫的意見回饋和附上的截圖見「意見回饋」。

為了知道有多少人來試玩、大家玩到哪裡、在哪裡卡住，我們用 GoatCounter 做匿名統計。你的瀏覽器會在這些時候送出一筆紀錄：

  • 進入遊戲；
  • 走到進度點，例如看到開始畫面、開始遊戲、教學走到第幾步、後院擺滿時有沒有跳出合成提示與照著做、第一次合成或交委託、每一章開始與完成、前幾章的劇情段落演到哪、突破境界、第一次修繕（含引導做到哪一步）、第一次合兩座產出點的教學做到哪、在藏經閣讀藥方筆記、按下「去藏經閣讀」、熬藥、派人下山、穿越者插曲出現／交付／看完或略過、看到並按下「報名封測」、報名後回到遊戲、按下「分享給道友」；
  • 可能卡住或用到某個功能時，例如靈力用完、靈石不夠回滿靈力、熬藥失手、打開貨郎、圖鑑、排行榜或近期更新公告、點了棋盤上方說明欄的待辦提示（是自動跳出還是自己打開）、從青玉山回後院是按哪個（按鈕、月洞門或返回鍵）、修好房子時是從哪裡點進修繕的、領圖鑑的靈石、靈力用完那一刻在第幾章與這次打開後玩了幾分鐘的區間、靈力用完跳出的「歇一歇」卡上點了哪一件不用靈力的事、熬藥時開的是第幾階的藥、熬藥中打開藥房時還剩幾分鐘的區間（例如 2～5 分鐘）、熬哪一階失手、用靈石催火或叫下山的人提早回來、夥伴體力用完、研讀還沒讀完時打開書桌、在網頁版完結的恭喜卡上按「產生引繼碼」、點了用完的產出點時遊戲有沒有指給你別座能點的，以及之後新增的玩法（例如派夥伴遠行）用到時（同一種每天最多一次）；
  • 每天第一次打開時，送出「這是第一次玩之後的第幾天」（例如第 1、2、3、7、10 天）、「連續玩到第幾天」、「總共玩過幾天」，以及上一次有玩的那天大約開了幾次、玩了多久的區間（例如 3～4 次、15～30 分鐘）。第一次玩的日期、每天開了幾次這些數字只存在你自己的瀏覽器裡，不會送出，送出去的只有區間；
  • 離開遊戲時，送出這次大約玩了多久的區間（例如 5～15 分鐘），以及離開那一刻大概在做什麼（例如在看劇情、靈力用完、一陣子沒點）；回來時送出離開了多久的區間（例如 2～8 小時）；
  • 遊戲版本、字級設定、音樂音效開關（每天最多一次），以及程式出錯時的簡短錯誤代碼（不含你的任何資料）。

每筆紀錄的內容只有：上面這類事件的名稱、從哪個網址連過來、螢幕大小，以及瀏覽器與連線本身會帶的技術資料（例如瀏覽器種類、IP 位址）。我們不使用 cookie，統計也不送出任何能認出你的編號。GoatCounter 只用這些資料算出不重複人數，不存 IP，也不會拿來追蹤或辨識你是誰。

為了避免同一件事一直重複記，你的瀏覽器會在本機記下「哪些事件今天或曾經送過」，這份紀錄只存在你自己的瀏覽器，不會傳到我們這邊。

排行榜

遊戲裡的排行榜會在你突破境界、完成一章、或重取道號時，送出一筆成績，內容只有：

  • 你在遊戲裡取的道號（例如「清風」，不是你的真名）；
  • 目前的境界與修為；
  • 一個隨機產生的裝置編號：第一次用到排行榜時由你的瀏覽器隨機產生、存在你自己的瀏覽器裡，只用來讓同一台裝置只留一筆最好的成績，從它認不出你是誰。

這些資料只用來排名，存在開發者自己的 Google 試算表（透過 Google Apps Script 接收）。打開排行榜時，你的瀏覽器會帶著同一個裝置編號去讀前十名與你自己的名次。不雅的道號會被換成「無名道友」或刪除。想刪掉你的那一筆，請寫信到 contact.ai.coder@gmail.com，附上你的道號與大約的境界即可。

意見回饋

在「設定 → 意見回饋」寫下的意見，送出時會帶著：你寫的文字、選的類別（建議、卡住了等）、遊戲版本、目前的境界與章節、遊戲裡的天數、螢幕大小，以及上面「排行榜」那個隨機裝置編號（用來擋同一台裝置短時間內重複送出）。不會送出你的名字或聯絡方式；請不要在意見裡寫自己的個人資料。

意見存在開發者自己的 Google 試算表，只用來改進遊戲。沒有網路時會先存在你自己的瀏覽器，下次打開遊戲再送。想刪掉你送過的意見，請寫信到 contact.ai.coder@gmail.com，附上大約的送出時間與內容。

意見回饋的截圖

收什麼：寫意見時，你可以自己選擇附上最多 2 張截圖，不附也完全沒關係。我們只收你挑的那幾張圖，不會自己去讀你手機或電腦裡的其他照片。截圖會跟你那則意見綁在一起。

送出前請看一下：截圖上方的通知、聊天訊息、電話、名字、大頭照、別人的臉，都可能被一起拍進去。請先裁掉或塗掉，只留遊戲畫面就好。

拿來做什麼：只用來看懂你說的問題、把遊戲改好，例如哪裡字被擋住、哪一關卡住。不拿去做宣傳、不放進遊戲、不公開，也不拿來認出你是誰。

存在哪裡：開發者自己 Google 雲端硬碟裡的私人資料夾（不開放分享連結），透過接收意見的同一支 Google Apps Script 存進去。

誰看得到：只有開發者本人。開發者會把意見和截圖放在只有自己能開的私人審閱頁面上看，也會用 AI 助理（Anthropic 的 Claude）幫忙整理、讀懂意見，所以截圖可能會交給它處理。

保存多久：收到後最多 90 天就刪除（雲端硬碟和審閱頁面上的都刪）。意見處理完、截圖用不到了，會更早刪。你寫的文字意見照上一段的說明另外保存。

想刪掉你的截圖：寫信到 contact.ai.coder@gmail.com，說大約什麼時候送的、意見寫了什麼，不用說理由。我們收到後 3 天內停止使用，14 天內刪除，刪完回信告訴你。

不提供給別人：截圖不賣、不送、不給任何其他人或公司使用。只會經過上面提到的 Google（存放）和 Anthropic（整理）這兩個服務，它們是幫開發者處理資料的工具，不是拿去自己用。

截圖裡不小心有別人的資料：如果我們看到截圖裡有別人（或你自己）的名字、臉、對話、電話、帳號之類的資料，不會去看那部分、不會轉傳、也不會另外存，會在發現後 3 天內把那張截圖刪掉，只留你的文字意見。如果是身分證、銀行卡、密碼這類更敏感的東西，發現就馬上刪。如果你是被拍進別人截圖的那個人，也可以直接寫信來，告訴我們大約的時間和畫面內容，我們一樣會刪除並回信。

遊戲進度存在哪裡

你的遊戲進度和設定（例如音量）只存在你自己瀏覽器的本機儲存空間（localStorage），不會傳到我們這邊。清除瀏覽器資料就會刪除進度。

第三方服務

  • GitHub Pages：本網站由 GitHub 代管。GitHub 可能依其政策記錄連線的技術資料（例如 IP 位址）。見 GitHub 隱私權聲明。
  • GoatCounter：匿名試玩統計，見上方說明與 GoatCounter 隱私權政策。
  • Google 試算表、雲端硬碟與 Apps Script：排行榜的成績與意見回饋存在試算表，意見附的截圖存在雲端硬碟的私人資料夾，見上方「排行榜」「意見回饋的截圖」與 Google 隱私權政策。
  • Anthropic（Claude）：開發者用來整理、讀懂玩家意見與截圖的 AI 助理。見 Anthropic 隱私權政策。
  • Google Fonts：遊戲字型從 Google Fonts 載入，你的瀏覽器會向 Google 送出請求。見 Google 隱私權政策。

封測報名

如果你透過我們提供的報名表單留下 Email，我們只用它來寄封測邀請，不會提供給他人；想取消可以寫信告訴我們。
