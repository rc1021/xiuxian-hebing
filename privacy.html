隱私權政策

《修仙合併：裂界重生》網頁試玩版　最後更新：2026-11-04

我們收集什麼

目前的網頁試玩版不收集任何個人資料：沒有帳號、沒有登入、沒有廣告，也不使用 cookie。

為了知道有多少人來試玩、大家玩到哪裡，我們用 GoatCounter 做匿名統計。每次進入遊戲，以及走到幾個進度點（開始教學、教學走完或略過、完成某一章、按下「報名封測」）時，你的瀏覽器會送出一筆紀錄，內容只有：哪個進度點、從哪個網址連過來、螢幕大小，以及瀏覽器與連線本身會帶的技術資料（例如瀏覽器種類、IP 位址）。GoatCounter 只用這些資料算出不重複人數，不存 IP，也不會拿來追蹤或辨識你是誰。

遊戲進度存在哪裡

你的遊戲進度和設定（例如音量）只存在你自己瀏覽器的本機儲存空間（localStorage），不會傳到我們這邊。清除瀏覽器資料就會刪除進度。

第三方服務

  • GitHub Pages：本網站由 GitHub 代管。GitHub 可能依其政策記錄連線的技術資料（例如 IP 位址）。見 GitHub 隱私權聲明。
  • GoatCounter：匿名試玩統計，見上方說明與 GoatCounter 隱私權政策。
  • Google Fonts：遊戲字型從 Google Fonts 載入，你的瀏覽器會向 Google 送出請求。見 Google 隱私權政策。

封測報名

如果你透過我們提供的報名表單留下 Email，我們只用它來寄封測邀請，不會提供給他人；想取消可以寫信告訴我們。

之後的改變

正式上架的 App 若加入廣告、更多數據分析或購買功能，會先更新本頁，寫清楚收集的項目與用途。
